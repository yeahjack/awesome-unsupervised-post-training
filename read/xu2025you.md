## When-to-Adapt audit

- **Auxiliary taxonomy:** `Timing Regime=Full-Cohort Transductive Adaptation`; `Visibility Scope=Full target cohort`.
- **Two-axis coding:** `Input Visibility=Offline`; `Update Persistence=Cumulative`; `Reset Boundary=Cohort Boundary`.

- **When the update is triggered:** the update is triggered on an unlabeled cohort from the same domain / task first, then inference is run uniformly with the adapted adapter.
- **Whose sample it serves:** the current cohort's update primarily serves this cohort and its same-distribution samples, not the immediate inference of any single sample.
- **Whether parameters/state accumulate:** the adapter accumulates within the cohort; reinitialization is usually needed when switching to a new cohort / distribution — this is mostly implicit in the protocol.
- **Reset boundary:** so it is closer to cohort-level adapter adaptation than per-sample adapt-reset.

## 1. UPT Assignment Rationale

SyTTA belongs to **Family I — Prediction-Statistic Optimization** (local-state / adapter shaping based on intrinsic LM statistics).

- **Signal source is fully intrinsic:** both of SyTTA's optimization objectives come from the model's own intrinsic statistics, with no reliance on external labels, human feedback, or external verifiers:
  - *Input Distribution Adaptation (IDA):* minimize the perplexity (NLL) of the input tokens — the model's own intrinsic measure of input distribution.
  - *Output Confidence Shaping (OCS):* minimize the predictive entropy of the output next-token distribution, with a reverse-KL constraint to keep the adapted model close to the base model — all based on the model's own logit distributions.
- **Carrier is a lightweight LoRA adapter:** parameters are updated at test time via LoRA (rank=8, on q_proj and v_proj only) — a direct-optimization paradigm.
- **Token-level operation:** the adaptation only generates an extremely short prefix (typically k=4 tokens) and computes entropy and KL signals on that prefix — token-level optimization.
- **No external supervision:** the whole pipeline is "question-only" and never accesses ground-truth answers.

## 2. Problem Addressed

When LLMs are deployed in specialized domains (finance, medicine, agriculture, etc.), they face **distribution shift**: domain-specific terminology, language patterns, and knowledge requirements differ substantially from the pretraining distribution, degrading performance.

Traditional solutions (SFT, RLHF, RAG) all require high-quality annotated data or an external knowledge base, which is hard to obtain in label-scarce domains. SyTTA targets **test-time** adaptation: lightweight tuning driven by self-supervised signals on unlabeled domain questions, narrowing the gap between training and deployment distributions.

Core challenges:
- Optimizing only input-side perplexity does not directly control generation quality.
- Optimizing only output-side entropy easily causes degeneration and collapse.
- We need stable, effective adaptation at extremely low compute (only 4 extra tokens per query).

## 3. Method

SyTTA couples two complementary self-supervised signals on a shared short-prefix context to perform test-time adaptation:

### 3.1 Input Distribution Adaptation (IDA)

Minimize the prompt perplexity of the input question (equivalent to NLL):

$$\mathcal{L}_{\text{IDA}}(\theta') = -\frac{1}{m}\sum_{i=1}^{m} \log p_{\theta'}(x_i \mid x_{<i})$$

- Use a **gating mechanism**: optimize only the difficult samples whose NLL under the base model exceeds a threshold.
- For selected samples, the loss is scaled in proportion to their NLL — focusing on harder inputs.

### 3.2 Output Confidence Shaping (OCS)

Apply output-side regularization on the short prefix $\bar{y}(x)$ (length k, typically k=4) generated by the model:

- **Entropy term:** minimize the next-token predictive entropy of the adapted model on the prefix.
  $$\mathcal{L}_{\text{ENT}}(\theta') = \sum_{t=1}^{k} H(p_{\theta'}(\cdot \mid x, \bar{y}_{<t}))$$
- **Reverse-KL term:** constrain the adapted model to the base model's reference distribution to prevent drift and collapse.
  $$\mathcal{L}_{\text{KL}}(\theta') = \sum_{t=1}^{k} D_{\text{KL}}(p_{\theta'}(\cdot \mid x, \bar{y}_{<t}) \| \text{softmax}(z_t^{\text{ref}}(x)))$$
- Combined: $\mathcal{L}_{\text{OCS}} = \mathcal{L}_{\text{ENT}} + \lambda_{\text{KL}} \mathcal{L}_{\text{KL}}$.

### 3.3 Two deployment modes

- **Static-Ref:** the prefix and base-model reference logits are pre-computed and cached by the frozen base model; adaptation needs only one forward pass — lowest compute cost (the recommended default).
- **Dynamic-Ref:** the prefix is generated by the adapting model in real time, and reference logits are computed online — suitable when tight tracking of the decoding trajectory is needed.

### 3.4 Dynamic Importance Weighting (DIW)

Dynamically balance the weights of the IDA and OCS objectives:

$$\mathcal{L}_{\text{total}}(\theta') = w_{\text{IDA}}^{(t)} \mathcal{L}_{\text{IDA}}(\theta') + w_{\text{OCS}}^{(t)} \mathcal{L}_{\text{OCS}}(\theta')$$

- Use an EMA to track total-loss magnitude and compute each objective's relative contribution.
- Use clipping ($\alpha_{\min}, \alpha_{\max}$) to prevent any single objective from dominating.
- Weight normalization keeps the total gradient magnitude stable.

### 3.5 Implementation details

- Use LoRA (rank=8) to update only q_proj and v_proj.
- Learning rate $1 \times 10^{-5}$, cosine scheduler, 1 epoch.
- Greedy decoding, accelerated with the vLLM engine.
- Cohort-level adaptation: one self-supervised adaptation pass over a batch of same-domain questions, then freeze parameters to generate answers.

## 5. Evaluation metrics and main results

### Metric

- **ROUGE-L_sum** (×100): the primary metric, measuring sentence-level overlap between generated and reference answers.

### Main results (Table 2)

Compared with the base model, Tent, EATA, and TLM on four base models (LLaMA 3.2-3B, LLaMA 3.1-8B, Qwen 2.5-7B, Qwen 2.5-14B):

| Key finding | Detail |
|----------|------|
| **Consistent gains** | SyTTA beats the base model and prior test-time-adaptation methods across all models and datasets. |
| **Largest gain** | On Agriculture + Qwen 2.5-7B, SyTTA (just 4 extra tokens) lifts ROUGE-L_sum by over **120%**. |
| **Entropy-only methods fail** | Tent and EATA often collapse to near-zero scores on autoregressive LLMs. |
| **TLM unstable** | Optimizing perplexity alone (TLM) is a strong baseline but collapses on Dolly and rarely reaches the best score. |
| **Average gains** | DomainBench: 40–60%; InstructBench: 15–22%. |
| **Static-Ref vs Dynamic-Ref** | Static-Ref is more stable in most cases and performs comparably or better — recommended as the default. |

### Key analytical conclusions

- **Prefix length:** k=4 beats k=16; most useful adaptation signal concentrates in the first few high-entropy tokens.
- **KL regularization:** effectively prevents adaptation drift; gains are larger in Dynamic-Ref mode (acts as a trust-region constraint).
- **Dynamic Importance Weighting:** improves ROUGE-L_sum on most models, with larger effect on the LLaMA family.
- **Scale trend:** within the LLaMA family, larger models benefit more; within the Qwen family, 7B outperforms 14B (Qwen's stronger post-training alignment leaves less room for test-time adaptation).
